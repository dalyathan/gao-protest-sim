# Independent methodology review (2026-11-12)

Fresh reviewer agent (no prior context), briefed on design + results, asked to critique as an
empirical legal researcher, ML-evaluation researcher, GAO protest attorney, and game theorist.

## Top "do NOT" list (ranked)
1. Building case files from the decision being predicted (label leakage). -> Outcome-blind extraction (Background + allegations only), keyword screen, blind audit.
2. Claiming accuracy at the base rate (21/24 = always-lose). -> AUROC, balanced accuracy, sustain recall/precision, Brier; always show trivial baseline.
3. Tuning on the same 8 cases. -> They are the DEV set. Freeze (git tag + prompt/param hash). Touch test set once.
4. Calibrating free play to published cases (circular: they're selected). Free-play CA 9/11 may be closer to reality (GAO effectiveness ~50%). -> Calibrate free play to GAO annual aggregate stats; score only real-path games vs individual decisions.
5. Treating 24 games as 24 observations (effective N≈8, 1 sustain). -> Aggregate per case; cluster bootstrap CIs.
6. Hand-written sustained case (style leakage). -> Same pipeline for all, or drop it.
7. Hand-picking sustains / raw accuracy on oversampled set. -> Pre-fixed strata, random within label; report per stratum + reweighted to base rate.
8. Mixing dismissals with denials; scoring all-grounds-dropped as loss. -> Separate merits vs dismissals; in forced path, force >=1 ground or count as abstention.
9. Leaning on RL / Priest-Klein claims built on invented payoffs. -> Present as illustration with sensitivity sweeps, or cut.
10. Claiming "first"; demoing as a prediction tool (UPL/reliance risk). -> Narrow claim (protective-order information sets in a deadline-bound forum); demo as strategy exploration.

Flaws in proposed next steps: true "pre-filing info" ablation impossible from decisions alone (state as limitation); single-LLM baseline must get identical input; add logistic regression on ground category; ~20 cases => CIs of +/-30 pts.

## Why a venue would reject now
No skill above majority class; N≈8; label leakage; post-hoc tuning; no multi-agent vs single-prompt ablation; invented parameters, no sensitivity analysis; no expert validation; reproducibility (model version, temperature, seeds).

## Practitioner realism gaps
Missing intervenor as active party; CO vs agency counsel blurred; pro se small businesses; debriefing + CICA stay deadlines; agency dismissal requests; agency report ~day 30, comments +10; SUPPLEMENTAL protests (grounds are more often added than dropped; many sustains come from them); outcome-prediction ADR (main CA trigger); costs for undue delay; 100-day clock; COFC; task-order thresholds. CA usually after agency report or ADR, often cheap. GAO requires prejudice, deferential review; spam-filter case = late-is-late doctrine (model used fairness, not doctrine). Counsel fee incentives absent.

## Pre-registerable plan (~$50)
1. Pre-register (OSF or dated git tag): prompts, params, model string, temperature, metrics, exclusions.
2. Sample: all decisions ~Aug 1 2026 -> fixed cutoff. Primary = merits: all sustains (~20-30) + 30 random denials (seeded). Secondary = 15 dismissals. Current 8 = dev only.
3. One outcome-blind extraction pipeline; outcome-word screen; 10% blind human audit.
4. Conditions: full sim real-path x3 (~180 games, ~$30); single-LLM same input x3 (~$5); allegation-only ablation x1 (~$10).
5. Primary metric: case-level AUROC of GAO agent's sustain probability on merits cases. Secondary: Brier (+decomposition), sustain recall/precision (stratified + reweighted), balanced accuracy. Cluster bootstrap 95% CIs; paired DeLong/bootstrap between conditions.
6. Baselines: majority, base-rate probability, single LLM, logistic regression on ground category.
7. Power: ~25 sustains + 30 denials => AUROC SE ≈0.07; detects 0.70 vs chance, not 0.70 vs 0.65. Between-condition gaps <0.15 = exploratory.
8. Free-play strategy: separate sensitivity analysis vs GAO aggregate stats.

## Verdict
Worth pursuing as a research testbed / strategy simulator (information sets, corrective-action dynamics) with honest calibration. Not credible as a prediction tool unless it beats base rate on a clean pre-registered test.
