Recent decisions for the test set. Save each one; Claude sorts them by date afterward.

How to do it

  1. Click a decision below. It opens on gao.gov.
  2. On that page, click the PDF ("View Decision") and save it to Downloads. Keep the file name GAO gives it.
  3. Tick the box here. Go at a normal reading pace.
  4. When you're done, tell Claude "check".

Need more (March 2025 to now)?

This list covers only the decisions already found. For the rest, use GAO's bid protest search (gao.gov/legal/bid-protests/search): set the decision date range, open each result, and save the PDF the same way. Decisions from August 2026 on are the most valuable.
